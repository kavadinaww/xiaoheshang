# 提示词规范（由飞猪 Seedance 提示词品质规范改造）

## 通用

1. 固定顺序：画风 → 角色（引用参考图 + 一句造型复述）→ 场景与光线 → 镜头（秒数、景别、一个运镜、一个动作）→ 声音（对白 / 旁白、背景音乐、环境音）→ 约束尾句。
2. 每镜一个动作、一个运镜；60 秒约 8 镜，每镜 5–10 秒分段生成，后期拼接（比一次 60 秒稳）。
3. 同画面最多 2 个角色（小满、松师父），可加一只猫、一只鸟。
4. 镜头 1 第一秒就有动作。
5. 对白写清是谁说、语气，台词放引号内；约每秒 4 字。动画角色可以对口型，但嘴型要小，避免夸张。
6. 画面不生成任何文字、logo、水印、真实寺名、佛像特写。
7. 背景音乐必写：风格 + 乐器 + 情绪，音量低于人声；环境音必写。

## 画风尾句（定稿后二选一写死）

- A：3D 国风动画电影质感，暖色柔光，水墨远山背景，材质干净，色彩以灰蓝、赭黄、银杏黄为主，不是写实真人。
- B：2D 水墨淡彩动画，宣纸纹理，线条柔和，留白多，色彩以灰蓝、赭黄、银杏黄为主。

## 固定约束尾句

角色造型与参考图完全一致（光头、服装、配色、身材比例），前后镜头一致；手部自然、五官稳定、动作缓慢自然；画面中不出现任何文字、字幕、logo、水印、真实寺名、佛像特写、宗教符号主视觉；不出现其他动画 IP 形象；清晰稳定，无闪烁、重影、变形。

## 示例（第 1 镜）

```
[画风尾句]
角色：参考图1 小满（8岁小和尚，圆脸大眼，光头，灰蓝短褂，草鞋，背小竹篓）。
场景：秋天上午，云半寺小院，老银杏下落满黄叶，柔和侧光。
镜头1（0-5秒）：中景，镜头轻微跟拍。开场第一秒小满就挥着竹扫帚用力扫落叶，一阵风吹来，叶子又落了一地，小满停下，鼓起脸。
对白（小满，童声，委屈）："师父，我扫了一上午，叶子怎么还在掉？"
背景音乐：古琴与箫，轻快带点俏皮，音量明显低于人声；环境音：风声、扫帚刷地声、落叶声。
[固定约束尾句]
```
