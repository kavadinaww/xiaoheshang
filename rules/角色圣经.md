# 角色圣经（初稿，待人定稿后标【定】）

每条视频都从同一套角色参考图生成，保证系列感。定稿图存 `assets/characters/`（定稿前为空）。

| 项目 | 设定 |
| --- | --- |
| 小和尚 | 小满，约 8 岁，圆脸、大眼、光头带浅青头皮，灰蓝短褂、草鞋、背小竹篓；好奇、爱问“为什么”、偶尔偷懒 |
| 老和尚 | 松师父，约 70 岁，白眉长、清瘦、赭黄旧短衫、手拄竹杖；话少、慢、爱用身边东西打比方，不说教 |
| 地点 | 虚构“云半寺”：山腰小院、一棵老银杏、一口井、菜园、石阶、竹林；不用真实寺名 |
| 画风 | 待定二选一：A 3D 国风暖色动画（软光、水墨远山）；B 2D 水墨淡彩。全系列只用一种 |
| 声音 | 小满：童声清亮、语速偏快；松师父：低沉温和、语速慢、停顿多 |
| 固定开场 | 0.5 秒内小满做动作 + 抛出具体问题 |
| 固定结尾 | 松师父一句 ≤ 15 字收住 + 小满一个小反应（点头、挠头、笑）+ 片尾系列名 |

## 与已有 IP 的区分（自审必查）

- 小满不穿白/米色长袍，不用大头比例过分夸张的 Q 版，不说“师父，我想……”式固定口头禅。
- 主色：灰蓝 + 赭黄 + 银杏黄；避开白衣小和尚 + 粉嫩配色。
- 名字、片尾标识、字幕字体都用自有设计。
