# 合规边界【定】（只有人能改）

## 定位

账号对外是“国风寓言动画 / 传统文化故事”，不是“佛学知识分享”。讲故事、讲生活道理；不讲经、不劝信、不卖法物。

依据：《互联网宗教信息服务管理办法》（2022-03-01 施行）第六条：通过公众账号、音视频等向社会公众提供宗教教义教规、宗教知识、宗教文化、宗教活动等信息，需取得互联网宗教信息服务许可，申请人须为依法设立的组织；第十五条：讲经讲道仅限持证宗教团体、寺观、院校在其自建平台上由教职人员进行。
原文：https://www.cac.gov.cn/2021-12/20/c_1641594960049078.htm

开号前建议请懂宗教事务和网络内容合规的律师确认一次（`ledgers/需要你.md` 第 1 项）。

## 可以做 / 不做

| 可以做 | 不做 |
| --- | --- |
| 出自佛经、禅宗公案、民间的寓言故事，重写成生活道理（盲人摸象、小和尚挑水） | 讲解经文教义、念经诵咒、“这样修行能消业” |
| 成语典故溯源（天花乱坠、一尘不染、当头棒喝），注明出处 | 劝人信教、皈依、拜师 |
| 虚构寺院“云半寺”的生活场景、节气、山水 | 卖开光、法物、祈福、算命、超度、供灯，带货任何宗教用品 |
| 原创卡通小满、松师父 | 冒充真实僧人、真实寺院、高僧语录、名人 IP |
| 结尾一句生活启发 | 贬低任何宗教或无宗教者、迷信、灵异、因果报应吓人 |

## 否决项（任一命中不发布）

1. 讲经说法、教义解读、念诵。
2. 劝信、皈依、引流到宗教场所或社群。
3. 卖法物、开光、祈福、算命、超度、供灯；任何宗教用品带货。
4. 冒充真实僧人、寺院；引用无出处的“高僧语录”。
5. 贬低任何宗教、民族、人群；迷信、恐吓。
6. 与他人动画 IP（含一禅小和尚）造型、名字、口头禅相近。
7. 未勾选 AI 生成声明。
8. 典故出处或读音未核对。
9. 画面出现真实寺名、真实佛像特写、宗教符号做主视觉。

## 用词

- 账号名、简介、标题、话题标签不用“佛”“禅师”“法师”“寺”“经”等易触发宗教审核的字眼。
- 话题标签用：#国风动画 #传统文化 #寓言故事 #成语故事 #治愈。
- 角色称呼：小满、师父 / 松师父。
