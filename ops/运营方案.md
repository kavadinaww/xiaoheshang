# 运营方案：每天 3 个定时任务（北京时间）

每个任务第一步：`git pull`，读 `rules/` 三个文件、`log/生产与发布日志.md` 最后 30 行、`ledgers/需要你.md`。
每个任务最后一步：在日志追加一行状态（✓◐−○!），`git commit` + `git push`。
“需要你”里有未完成的【定】项（定位、画风、预算、平台）时：只做准备工作，不花生成费、不发布，状态记 −（原因：等人定）。

## 06:30 数据采集

1. 打开各平台创作者后台（已登录的浏览器），读最近 7 天作品：播放、2 秒跳出、5 秒留存、完播率、平均观看秒数、点赞、评论、转发、收藏、涨粉。
2. 按作品发布时间，把达到 24h / 72h / 7d 时点的数据追加进 `data/works.csv`（一条作品一个平台一个时点一行，不改旧行）。
3. 跑 `python3 scripts/percentile.py data/works.csv`，结果写 `data/percentile_latest.csv`。
4. 读评论：反复出现的问题进 `ledgers/需求台账.md`；纠错（出处、读音、角色走样）进 `ledgers/更正台账.md`。
5. 后台读不到（未登录、扫码失效）：进需要你（类别：登录），状态 ◐。

## 09:30 批前复盘 + 创作（每天 1 批 2 条）

1. 批前复盘（规则“批前复盘”5 步），写入新建的 `batches/第N批_YYYYMMDD.md` 开头。没有复盘不许往下做。
2. 选题 2 个：选题库（`ledgers/选题库.md`）按栏目轮转 + 需求台账 ≥ 3 人的问题优先；用掉的在选题库打勾。
3. 剧本 2 条（结构见规则“开头前 2 秒”+ 下方模板），两条共享同一个实验变量。
4. 合规自查（`rules/合规边界.md` 否决项逐条）。
5. 关键帧：每镜 1 张（带角色参考图）；自查造型一致后进视频。
6. 视频：Seedance 参考图生视频，每镜单独生成，火山同时最多 2 个任务。
7. 自审每镜：造型一致、手脸、乱码、读音、合规、第 1 镜 0.5 秒有动作。不过重生成，同镜最多 3 次；仍不过就换镜头写法，记更正台账。
8. `python3 scripts/finish.py batches/第N批_xxx/作品编号/finish.json` 拼成成片；`python3 scripts/qc.py 成片.mp4`，QC 不过不发布。
9. 各平台文案包（标题、封面字、话题、简介），写进批次文件。
10. 成片超过当天发布需要的，标“备用”，计入素材水位。

### 60 秒剧本模板

1. 0–2 秒：小满动作 + 具体提问。
2. 2–8 秒：松师父不直接答，抛反问或做一个动作。
3. 8–45 秒：故事本体 3–5 镜，每镜一个动作。
4. 45–55 秒：小满自己说出领悟。
5. 55–60 秒：松师父一句 ≤ 15 字收尾 + 片尾系列名。

## 11:30–21:00 发布

| 平台 | 时段（起步试验） | 包装 |
| --- | --- | --- |
| 抖音 | 12:00 / 21:00 | 短问句标题 |
| 视频号 | 07:00（次日）/ 20:00 | 结尾那句话做封面，利于转给家人 |
| 快手 | 12:00 / 20:00 | 口语标题，评论区置顶一句提问 |
| 小红书 | 21:00 | 情绪价值标题 + 3 行故事梗概 |
| B 站 | 周六 19:00 | 每周合集横版 5 分钟 |

- 能用浏览器在已登录后台上传的自动传；不能的进需要你，附文件和文案包。
- 每发一个平台记一行：作品编号、平台、作品 ID / 链接、时间、状态（已提交 / 过审 / 驳回）。

## 21:30 日报 + 看板

1. `python3 scripts/dashboard.py` 生成 `dashboard/index.html`（今天、需要你、作品分位、规律、运转五块）。
2. 日报写进日志：今日状态行汇总、最高/最低分位作品、实验进展、明天计划、需要你新增项。
3. 每周日加做：规则里“每周”那几项。

## 计费参考

1080p Seedance 约 3.7 元/秒（飞猪实测 30 秒约 112 元）。60 秒成片约 225 元，加重生成约 260 元/条；每天 2 条约 450–520 元。720p 或 45 秒可降到约一半。实际以火山账单为准，日志每批记花费。
