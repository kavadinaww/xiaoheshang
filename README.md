# 小和尚听故事 · 自我迭代短视频系统

多平台短视频账号：小和尚“小满”听老和尚“松师父”讲故事，落点是生活智慧。
本仓库是这套账号的“运营中控”：规则、日志、台账、剧本、脚本都在这里，每次定时运行按规则读写这些文件。

结构照搬飞猪投放视频 v1.5 那套模块（它本身借鉴了咸水数据中心），换成内容账号的指标：
飞猪看 ROI 和下单，这里看完播、留存、涨粉、转发。

## 目录

| 路径 | 作用 | 对应飞猪模块 |
| --- | --- | --- |
| `rules/自我迭代规则.md` | 总规则：状态口径、需要你、同龄分位、证据分级、实验、开头规则、水位、QC、安全阀 | 飞猪_自我迭代规则 v1.5 |
| `rules/合规边界.md` | 可以做 / 不做、否决项（【定】，只有人能改） | 业务前提 + 否决项 |
| `rules/角色圣经.md` | 小满、松师父、云半寺、画风、声音、固定开场结尾 | 剧本规范 + 品牌要求 |
| `rules/提示词规范.md` | Seedream 关键帧 / Seedance 视频提示词固定写法 | Seedance 提示词品质规范 |
| `ops/运营方案.md` | 每天 3 个定时任务各做什么，一步一步 | 运营方案 |
| `ops/定时任务提示词.md` | 直接粘进定时任务的提示词 | 定时运行指令 |
| `log/生产与发布日志.md` | 每批、每次运行一行状态 | 生产与投放日志 |
| `ledgers/` | 需要你队列、实验登记、需求台账、更正台账、选题库 | v1.5 台账 |
| `batches/` | 每批一份：批前复盘 + 剧本 + 提示词 + 自审结果 | 第 N 批剧本与提示词 |
| `data/works.csv` | 每条作品每个平台每个时点的数据 | 视频数据 |
| `scripts/percentile.py` | 算 24h/72h/7d 同龄分位、每周相关 | 同龄分位 |
| `scripts/finish.py` | ffmpeg 拼接分镜、配音、背景音乐、字幕、响度标准化 | finish.py |
| `scripts/qc.py` | 成片 QC：分辨率、时长、响度、真峰、黑帧/静帧 | 成片 QC 数值线 |
| `scripts/dashboard.py` | 从 data 和台账生成静态看板 `dashboard/index.html` | 数据中心看板 |

## 一次运行的闭环

批前复盘 → 选题 → 剧本 → 关键帧 → 分镜视频 → `finish.py` → 自审 + `qc.py` → 多平台发布 → 写日志状态行 → 数据采集 → `percentile.py` → 规则升降级 → 下一批复盘。

## 启动前要人定的事

见 `ledgers/需要你.md`。在这些项没定之前，定时任务只做准备工作（选题库、剧本草稿），不花生成费、不发布。

## 依赖

- Python 3.10+（仅标准库）
- ffmpeg / ffprobe（带 libass、loudnorm、ebur128）
- 生成：火山方舟 Doubao-Seedream（关键帧）、Doubao-Seedance（视频），密钥只放环境变量 `ARK_API_KEY`，不进仓库
